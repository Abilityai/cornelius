## Description   
*[Written by Claude]*   
Implementation of EDTH's talent network strategy - building the tooling and systems to make EDTH the single best place to hire defense talent in Europe.   
## Core premise   
- Solve one problem really well: **talent scarcity** for defense startups   
- Give companies a single, clear reason to join EDTH: **hiring**   
- Once defense startups are in, component suppliers follow to sell into that ecosystem   
   
## What needs to be built   
### a) Partner model (events & hiring)   
- Partner signup and management system   
- Discount tiers: 20-40% for event sponsors, 10-20% for hackathon partners   
- Tracking: sponsorship → hires pipeline   
- Mental model: "€5K flat per hire" via sponsorship   
   
### b) Virtual hackathon participation   
- €2.5K virtual participation option   
- Fix talent onboarding flow per hackathon   
- Structured post-hackathon follow-up system to track actual hires   
   
### c) Job wall   
- Weekly job drops in Discord (automation)   
- Centralized job database   
- Job-seeker newsletter   
   
### d) Active profile search (light headhunting)   
- Request system for specific profiles   
- Newsletter visibility boost   
- Targeted challenges/events (e.g., computer-vision day)   
- Pricing: €5K flat + €5-15K success fee   
- Anonymous or branded options   
   
### e) Talent pool access   
- Dedicated company view into talent pool   
- Weekly email with interested profiles   
- Double-opt-in introductions   
- Solve: "companies don't have time to look through pool themselves"   
   
## Pricing tiers   
|           Stage |    Price |
|:----------------|:---------|
| Pre-fundraising |     €500 |
|       Post-seed |   €2,000 |
| Large companies |   €5,000 |

Alternative: First hire free, then €5K (seed) / €10K (Series A+)   
## Growth targets   
- 20 companies in 6 weeks → 50 → 100   
- Revenue target: 100 × €1,000 = €100,000   
   
## Longer-term expansion   
Once hiring is nailed:   
- B2B introductions   
- EU / Ukraine market expansion   
- Tender applications   
   
## Implementation priorities   
1. Partner signup flow + CRM integration   
2. Job wall automation (Discord + database + newsletter)   
3. Talent pool interface for companies   
4. Post-hackathon hire tracking system   
5. Profile search request workflow
