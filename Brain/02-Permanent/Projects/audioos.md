## Description   
 --- 
What is it   
> An interactive audio content platform/neverending podcast/audio assistant/next generation of podcast   

Goals   
> Enable anyone to enjoy endless news/stories/music/conversations through an audio interface   

MVP   
> STT→LLM→TTS pipeline    
> alt.   
> System message prompt for existing STS application
