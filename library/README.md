# Seed library

About 1,050 notes on decision-making, judgment and cognitive science, distilled from
published research and books (all `provenance: encountered` - recorded reading, not
anyone's own thinking):

| Folder | What |
|---|---|
| `Document Insights/` | ~890 research-finding notes across 57 sessions |
| `Books/` | ~141 atomic insights from 6 decision-science books |
| `03-MOCs/` | 13 maps of content - start at `MOC - Knowledge Base` |
| `02-Permanent/` | 10 example notes about the Zettelkasten method itself |
| `04-Output/` | one example article |

**It is not part of your brain until you ask for it.** A fresh Cornelius starts empty:
this folder sits outside the vault (`Brain/`), so it is not searched, not indexed and
not drawn in the Brain Orb. To add it - at first run or any time later:

```
/first-run --with-library
```

That copies these notes into `Brain/` (same folder layout, never overwriting a note
already there), rebuilds the index and refreshes the orb. The copies are yours from
then on; this folder stays as the untouched source. To take the library out again,
delete the copied folders from `Brain/` and run `/refresh-index`.
